# FiveM_Dx3DViewer
Phần mềm Windows xem / xuất model 3D GTA V và FiveM. Phù hợp người làm shop quần áo, xe, vũ khí, inventory, hoặc cần xem resource trước khi đưa lên server.

---

## Bạn nhận được gì

* Xem 3D file RAGE: YDR, YFT, YDD, YTD, YMAP…
* Thêm thư mục resource FiveM, lọc quần áo / xe / vũ khí
* Xuất model
* Xuất ảnh preview khung 3D
* Tự cập nhật — không phải tải lại full mỗi bản
* Hỗ trợ ngôn ngữ Tiếng Việt, English, ไทย

Không phải script FiveM. Chạy trên PC Windows, không cần vào game để xem model.

## Cài trên máy

**Yêu cầu**

* Windows 10/11 64-bit
* [Desktop Runtime .NET 10 x64](https://dotnet.microsoft.com/download/dotnet/10.0) (bản Desktop, không phải ASP.NET)


**Các bước**

1. Chạy `Dx3DViewer.exe`.
2. Lần đầu app tự cài vào `%LocalAppData%\Dx3DViewer`, tạo shortcut Desktop và Start Menu, tải phần còn lại từ server.
3. Mở shortcut lần sau. Có bản mới thì chỉ tải file thay đổi.

---

## Dùng nhanh

1. (Tuỳ chọn) Chọn thư mục GTA V có `gta5.exe`.
2. **Tài nguyên** → Thêm thư mục resource FiveM → **Tải**.
3. **Danh sách** → bấm file → cửa sổ 3D.
4. Chuột trái xoay, lăn zoom.
5. Xuất: đánh dấu model (Space / ô chọn) → **Xuất ra…** → thư mục **khác** thư mục gốc.

Gặp lỗi kích hoạt: copy đúng dòng `DX3D-…`, kiểm tra mạng, đúng máy đã gắn. Báo người bán nếu key thu hồi / hết hạn / đủ số máy.
